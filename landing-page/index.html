    FAQ

    Common questions

    Does EchoFootPrint block trackers?

    No. It visualizes tracking so you can see the ecosystem. Use a blocker if you want to stop requests.

    What data is stored?

    Detected domains, URLs, timestamps, pixel types, and platform labels—stored locally in IndexedDB.

    Is anything sent to servers?

    No. There is no telemetry or analytics. An optional IP lookup caches geo data locally.

    Can I clear my data?

    Yes. Use Settings → Clear All Data to delete detections, geo cache, and preferences.

    Which browsers are supported?

    Chromium-based browsers via Manifest V3 (e.g., Chrome, Edge). Firefox support is planned separately.
